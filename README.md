# Runescape-Addons
My collection of plugins for Runescape.

## Necromancy Stacks Audible Alert

Simple mod that makes it easier to keep track of what your Necromancy stacks are currently at via an audible alert when a threshold is reached.

Features:

    Audible alerts when Residual Soul reaches 3/5 stacks
    Audible alerts when Necrosis reaches 6/12 stacks
    Choose between Microsoft David or Microsoft Zira voice alerts
    Enable or disable alerts for each threshold
